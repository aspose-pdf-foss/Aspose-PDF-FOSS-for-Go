# Security Policy

## Reporting a vulnerability

If you believe you've found a security vulnerability in this library, please report it privately rather than opening a public issue.

**Preferred: GitHub Private Vulnerability Reporting.** Use the "Report a vulnerability" button under this repository's [Security tab](https://github.com/aspose-pdf-foss/aspose-pdf-foss-for-go/security/advisories/new). This keeps the report private between you and the maintainer and lets us track it as a GitHub Security Advisory.

**Alternative: email.** andrey.kaferi@aspose.com

Please include:
- A description of the issue and its potential impact
- Steps to reproduce (a minimal code sample is ideal)
- The version or commit you tested against

## What to expect

This project is maintained by one person, not a dedicated security team, so there's no formal SLA. In practice, expect an acknowledgement within a few days and a fix or mitigation as soon as reasonably possible given the severity. We'll credit reporters in the fix's commit message and the changelog unless you'd rather stay anonymous.

## Supported versions

Only the latest release (see [CHANGELOG.md](CHANGELOG.md)) is supported. The project is pre-1.0 (Semantic Versioning), so please upgrade to the latest release before reporting if that's practical for you.

## Disclosure

Please don't disclose the issue publicly until a fix has been released. We're happy to coordinate on timing for a public writeup or a CVE if one is warranted.
